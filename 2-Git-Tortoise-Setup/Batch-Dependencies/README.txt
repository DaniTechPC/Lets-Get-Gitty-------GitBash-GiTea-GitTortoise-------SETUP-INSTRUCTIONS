TortoiseGit Setup Dependencies
==============================

Keep this folder next to Setup-TortoiseGit.bat.

Required file:
  TortoiseGit_Settings.reg

The batch file resolves this folder relative to its own location, so the
setup can be copied to any folder or USB drive as long as this folder stays
beside the BAT file.


un-Classic-Windows-Menu.bat
  Removes the Windows Classic Menu registry setting if you want to restore the default Windows 11 context menu.
